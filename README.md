# reserva-inteligente-semcult
Sistema de Reservas Inteligente desenvolvido com Python (FastAPI), PostgreSQL e tecnologias web modernas, aplicado à disciplina “Aplicações de Cloud, IoT e Indústria 4.0” e à realidade da SEMCULT. Projeto acadêmico e prático para gerenciamento de espaços culturais, acadêmicos ou corporativos.
