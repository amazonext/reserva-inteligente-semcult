# 🤝 Contribuindo – Sistema de Reservas Inteligente – SEMCULT

Obrigado por se interessar em contribuir com o **Sistema de Reservas Inteligente – SEMCULT**!
Este documento descreve as diretrizes para contribuir de forma eficiente, organizada e colaborativa.

---

## 1. Como Contribuir

Você pode contribuir de várias formas:

- **Código:** novas funcionalidades, correções de bugs ou melhorias.
- **Documentação:** atualização do README, guias de desenvolvimento ou documentação técnica.
- **Testes:** criar ou melhorar testes automatizados.
- **Sugestões:** abertura de issues ou discussão de melhorias.

---

## 2. Fluxo de Contribuição (GitHub)

1. **Fork** este repositório.
2. **Clone** seu fork localmente:

   ```bash
   git clone https://github.com/seu-usuario/reserva-inteligente-semcult.git
   cd reserva-inteligente-semcult
   ```

3. Crie uma **branch** para sua feature ou correção:

   ```bash
   git checkout -b feature/nome-da-sua-feature
   # ou
   git checkout -b fix/descricao-do-bug
   ```

4. Faça suas alterações no código ou documentação.

5. Faça **commits claros e descritivos**:

   ```bash
   git add .
   git commit -m "Adiciona descrição clara da mudança"
   ```

6. **Push** da branch para o seu fork:

   ```bash
   git push origin feature/nome-da-sua-feature
   ```

7. Abra um **Pull Request (PR)** neste repositório principal.

- Descreva detalhadamente o que foi alterado.
- Referencie a issue, se houver.

---

## 3. Boas Práticas

- Mantenha o **código limpo e organizado**.
- Siga a estrutura do projeto (`backend/`, `frontend/`, `docs/`).
- Teste suas alterações localmente antes de enviar PRs.
- Evite commits grandes; prefira commits pequenos e claros.
- Atualize **requirements.txt** ou **package.json** se adicionar novas dependências.

---

## 4. Padrão de Nomenclatura de Branches

- **Features:** `feature/nome-da-feature`
- **Correções de bug:** `fix/descricao-do-bug`
- **Documentação:** `docs/atualizacao-doc`
- **Hotfixes:** `hotfix/descricao`

---

## 5. Issues

- Antes de criar uma nova issue, verifique se já não existe algo semelhante.
- Forneça um **título claro** e **descrição detalhada**.
- Inclua capturas de tela ou logs quando necessário.

---

## 6. Código de Conduta

Por favor, siga nosso [Código de Conduta](./CODE_OF_CONDUCT.md).
Respeito, colaboração e profissionalismo são obrigatórios para todos os colaboradores.

---

## 7. Contato

Se tiver dúvidas ou dificuldades para contribuir, entre em contato com os mantenedores através das **issues** ou pelo email listado no repositório.
